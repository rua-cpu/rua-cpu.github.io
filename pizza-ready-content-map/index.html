Pizza Ready · Content Layering Proposal

콘텐츠를 추가하는 것이 아니라
플레이 이유를 층으로 쌓는다

핵심은 하나의 Core Action(핵심 행동)이 Short Goal(단기 목표), Repeat Motivation(반복 동기), Mid-term Goal(중기 목표), World Progress(월드 성장), Long-term Franchise Progress(장기 프랜차이즈 성장)를 동시에 움직이게 만드는 것입니다.

문제

Step44 이후 Need 약화

새 기능을 여는 기대가 약해지면서 Upgrade의 의미가 숫자 상승으로 축소됩니다.

전략

Need Layering

같은 Upgrade가 Contest, Factory, World, HQ까지 동시에 진전시키도록 만듭니다.

목표

Retention + RV + LTV

광고 수를 억지로 늘리기보다, 목표를 앞당길 때 RV가 자연스럽게 선택되게 합니다.

“무슨 콘텐츠를 더 넣을까?”가 아니라 “하나의 Core Action이 몇 개의 Progress를 동시에 만들게 할까?”가 기준입니다.
01 · Layer Model

Pizza Ready 6-Layer 구조

각 Layer는 서로 다른 User Need(유저 니즈)를 담당합니다. 아래로 갈수록 즉시성, 위로 갈수록 장기성이 커집니다.

L5
HQ / Franchise
Long-term Purpose(장기 목적)
“왜 계속 해야 하지?”
전체 지점 성장을 하나의 장기 축으로 집계
L4
World Map / Branch Growth
Permanent Progress(영구 진행)
“내가 한 게 어디에 남지?”
Store 결과를 공간/외형 변화로 보존
L3
Factory / Live Event
Mid-term Goal(중기 목표)
“지금 더 해볼 이유는?”
Core 익숙함 이후 새로운 Progress 축 제공
L2

L1

“다음에 뭘 하지?”

IAP = Persistent Efficiency(지속 효율)

10 · Content Map

콘텐츠를 “목록”이 아니라
의존 관계와 역할로 본다

Content Map은 “어떤 콘텐츠가 존재하는가”보다 무엇을 받아서, 무엇을 진전시키고, 어디로 되돌려 보내는가를 한 화면에서 보는 맵입니다.

↑ Branch Grade와 Store 결과가 HQ Progress로 누적
↑ Mid-term 성과와 Core 성장 결과를 영구 시각화
↑ Core 행동을 새로운 Goal/Friction으로 전환하고 보상을 다시 Core로 환류
↑ 반복 행동을 Daily / Weekly / Seasonal 가치로 환산
↑ Core의 다음 행동과 다음 Unlock을 해석
