UI REVIEW PROCESS · 내부 논의 자료

기획 피드백을 줄이되,
색상 검토는 빼지 않는다

UI 피드백이 반복되는 문제를 해결하면서도, 레이아웃·컬러·강조 순서를 초기 단계에서 함께 검토하기 위한 프로세스 개선안입니다.

“색상은 완성 단계의 장식이 아니라, 정보 위계와 행동 유도를 만드는 UI 구조의 일부다.”
현재 문제 정의

“피드백이 많다”와 “기획서와 다르다”가 충돌하고 있다

UI팀은 반복 수정 비용을 줄이려 하고, 기획팀은 기획 의도와 다른 표현을 바로잡으려 합니다. 양쪽 모두 타당하지만 리뷰 구조가 분리되어 있지 않아 충돌합니다.

기획서 전달의도·레퍼런스·요소 정의
러프 시안레이아웃과 임시 표현 혼재
다수 피드백구조·색·디테일·추가 요청이 한 번에 등장
반복 수정앞서 수정한 요소가 다른 요소에 영향
일정 부담UI·기획·개발 모두 재작업 증가
결론

없애야 할 것은 색상 피드백이 아니라, 피드백의 혼합과 반복이다

권장 원칙
초기 시안은 레이아웃 + 대표 컬러 + 강조 순서를 함께 검토하고, 세부 장식과 미세 조정은 다음 리뷰로 분리합니다.
  • 기획은 컨셉·정보 구조·컬러 방향처럼 수정 비용이 큰 항목에 먼저 집중
  • UI는 회색 박스가 아니라 실제에 가까운 대표 색상을 넣어 검토 가능하게 준비
  • 개발 적용은 레이아웃뿐 아니라 컬러 시스템과 강조 순서가 승인된 뒤 진행
왜 색상이 빠지면 안 되는가

컬러는 5가지 UI 기능을 동시에 바꾼다

①
시각적 위계

무엇을 가장 먼저 보게 할지 결정

②
영역 구분

연출·플레이·보상 구역을 분리

③
시인성

아이콘·텍스트·버튼이 잘 보이게 함

④
행동 유도

누를 곳과 받을 보상을 직관적으로 표시

⑤
감정 전달

이벤트의 특별함·보상감·성장감 형성

Recommended workflow

복합 UI 권장 타임라인

D0기획 리뷰 및 범위 확정

목적, 유저 행동, 화면 구성, 필수 요소, 레퍼런스, 타깃 버전 확인

D1~D2초기 컨셉 제작

레이아웃 1~2안 + 대표 컬러 + 강조 순서 적용. 완성도는 60~70% 수준

D2컨셉 정합성 리뷰CONCEPT GO

구조·컨셉·컬러 방향·빠진 요소만 확인. 이 단계 이후 전면 컨셉 변경 제한

D3~D51차 시안 디벨롭

실제 화면 비율, 세부 컬러, 텍스트, 상태값, 주요 데코 적용

D5시안 리뷰 미팅GO / REWORK

필수 수정·선택 개선·추후 개선을 구분하여 한 번에 결정

D6~D7일괄 수정 및 최종 리소스

확정된 필수 수정만 반영하고 원본·Export·파일명·경로 전달

D8~D10개발 적용 및 실제 화면 QADONE

실기기에서 시인성, Safe Area, 텍스트, 버튼 상태, 애니메이션을 최종 확인

Feedback rules

피드백 횟수를 줄이는 5가지 규칙

① 단일 DRI기획 의견을 한 명이 취합해 전달필수

⑤ 실제 화면 승인단독 PNG가 아닌 인게임 Mock-up 또는 빌드로 최종 확인완료 기준

Meeting talk track

회의에서 사용할 핵심 문구

기획에서도 피드백 횟수를 줄이고 한 번에 취합해 전달하는 방식에는 동의합니다.

다만 이벤트 UI에서 색상은 단순한 디자인 완성도 영역이 아니라, 정보 위계·영역 구분·보상 강조와 직접 연결되는 기능 요소입니다.

따라서 색상을 제외한 레이아웃만 승인한 뒤 개발 적용하는 방식은, 실제 화면에서 대비 문제가 발견되어 오히려 전체 재작업이 커질 가능성이 있습니다.

초기 시안에서는 최종 디테일까지 요구하지 않되, 대표 색상과 주요 대비가 적용된 상태로 레이아웃과 함께 검토하는 방식을 제안합니다.

대신 기획 피드백은 컨셉·레이아웃·컬러 방향처럼 수정 비용이 큰 항목에 집중하고, 세부 표현은 1차 시안 리뷰에서 한 번에 취합하겠습니다.

One-line agreement

최종 합의안

러프 단계: 레이아웃 + 대표 컬러 + 강조 순서 확인

1차 시안: 세부 색상·디테일·완성도 일괄 피드백

개발 적용 후: 실제 화면에서 구현 문제만 수정

핵심은 색상 피드백을 없애는 것이 아니라, 색상의 방향과 기능은 초기에 결정하고 세부 조정은 다음 단계로 분리하는 것입니다.

UI 피드백 프로세스 개선 시각화 · 내부 회의 및 공유용
