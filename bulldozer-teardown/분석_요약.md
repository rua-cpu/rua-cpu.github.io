# Bulldozer Master 10.1.0 분석 요약

## 핵심 결론
- 게임은 채굴 아케이드 → 경영 자동화 → Worker 관리 → Secretary 캐릭터 메타 → World Map LiveOps 순으로 확장되고 있습니다.
- Android 10.1 공개 패치노트는 Worker/Shop 중심이지만, 현재 XAPK에는 Secretary/World Map/Event 관련 리소스와 데이터가 포함되어 있습니다.
- 수익화는 상품 자체보다 플레이 병목 직후의 RV/IAP 트리거 설계가 핵심입니다.
- 이번 패키지는 실제 XAPK ASTC Texture2D 469개를 포함하고, 주요 상품/RV/캐릭터/이벤트 화면에서 실제 리소스를 브라우저 디코딩합니다.

## 주의
- 미사용 리소스는 향후 업데이트 확정 증거가 아닙니다.
- 구버전 바이너리가 없으므로 리소스별 최초 추가 버전은 확정할 수 없습니다.
